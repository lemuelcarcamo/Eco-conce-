# Eco Conce - Sistema de Logística Sustentable y Encomiendas

Aplicación web completa desarrollada para la red de delivery cero emisiones en el Gran Concepción.

## Estructura del Proyecto
- `index.html`: Página principal con navegación por pestañas, cotizador, seguimiento de encomiendas estilo Starken, hubs y área de repartidor.
- `assets/style.css`: Sistema de diseño moderno, adaptativo (responsive) y sustentable con animaciones fluidas.
- `assets/script.js`: Lógica completa de cotización, persistencia en localStorage, seguimiento de códigos y panel de control con PIN de trabajador (23023).
